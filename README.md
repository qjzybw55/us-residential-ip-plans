## 三类“美国 IP”的区别，一分钟分清

风控平台判断一条 IP 可不可疑，看三样：ASN 属于数据中心还是民用运营商、同段 IP 有没有被大量代理共用、IP 归属地和账号注册地是否对得上。普通云服务器的 IP 段直接注册在机房服务商名下，第一关就过不去，Scamalytics、IPQualityScore 这类库会把它标成 Hosting/Datacenter。TikTok 会识别出 ASN 属于机房，Netflix 会弹代理提示，ChatGPT 频繁要求过验证码，问题都不在 VPS 性能上。

| 类型 | 本质 | 风控表现 | 适合的业务 |
| --- | --- | --- | --- |
| 双 ISP 家宽 IP | IP 段注册在运营商名下，机器仍在机房，走 9929、4837 这类线路接入 | 多数库识别为 ISP/Residential | TikTok 运营、电商注册、社媒养号 |
| 国际 BGP 数据中心 IP | 标准云服务器 IP，不做大陆优化 | 大概率标为 Hosting | 挂机、测速、对 IP 类型不敏感的临时任务 |
| 真实住宅 IP（NAT/静态） | 物理住宅宽带直接接入，NAT 版定期换 IP，静态版一人独享 | 最接近真人流量 | 长期小号矩阵、需要固定身份的账号 |

双 ISP 的说法来自商家宣传口径：IP 段同时注册在两个民用运营商名下，所以 IP 库读出来是家宽属性。机器该在机房还在机房，回程该走优化线路还走优化线路。真实民房 VDS 是另一种东西，硬件摆在人家房子里，IP 由 Atlas Networks、Astound Broadband、T-Mobile/Frontier 这类家庭宽带运营商直接分配。一句话区分：双 ISP 是属性像家宽，家宽 VDS 是本来就是家宽。

## 9929 和 4837 都是 68 元，差在哪

同一家、同一个入门价，9929 精简版给 50Mbps 带宽和 1000GB 流量，4837 基础版给 300Mbps 和 3000GB。带宽差了六倍，价格一样，因为两档卖的东西不一样：9929 卖的是回程线路质量，4837 卖的是管道大小。

## 家宽 VDS：多花的 100 元买的是什么

169 元/月的家宽 VDS 基础版，配置和 68 元的双 ISP 入门款拉不开差距，多出来的钱全花在 IP 的来源上。双 ISP 是让 IP 库读出来像家宽，VDS 是这台机器真的摆在西雅图或者洛杉矶的民房里，IP 由 Atlas Networks、Astound Broadband 这类运营商直接分配。

做 Stripe、PayPal、美国银行账户这类对 IP 极敏感的业务，或者给 TikTok、Instagram 主号做长期养号，这个差别值钱。只是注册几个账号、跑跑测评，68 元那档就够，多花的钱换不来对应的收益。

选哪个民房也有讲究。西雅图 Atlas Networks 偏美西，做仓储、物流相关的店铺更贴合；洛杉矶 Astound Broadband 适合加州本地化的店铺；T-Mobile/Frontier 的加州方案只卖不限流量，1 核 1G 的 399 元/月是不限量档里最便宜的。

这条线有两条硬限制必须先知道：官方标注为特殊产品，退款只退到账户余额，不会原路退回支付宝；部分 IP 段按 IP 提供方要求禁了 ping，ping 不通是正常现象，不代表机器有问题，用 ping 判断网络质量会得出错误结论。

## 退款、换 IP 和几个容易踩的坑

退款政策按产品线分，不是一句“48 小时无条件”能概括的。9929 和 4837 系列开通 48 小时内可申请全额退款，但带宽用量超过分配额度的 5% 或 20GB（取较小值）、产生安装费或支付处理费、以及被判定为滥用的，不在退款范围。48 小时之后按个案处理。家宽 VDS 只退网站余额。CN2 NAT 明确无退款。
